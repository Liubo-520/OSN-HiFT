# OSN-HiFT: verified data and frozen transfer models

Version 1.0.0 accompanies the study of source-paper effects, validation and few-shot
cross-solvent prediction in organic solvent nanofiltration. This repository contains
data, analysis code, evaluation outputs and loadable model weights. The unpublished
manuscript, author declarations and supplied graphical artwork are not included.

## Contents

- `data/raw/`: immutable OMD4SRNF exports, acquisition/source notes and checksums.
- `data/reference/`: verified ambient solvent values and descriptor source inputs.
- `analysis/data/`: curated domains, canonical paper-reference mapping and external additions.
- `analysis/results/`: benchmark predictions, fold assignments, calibration and nested-selection summaries.
- `analysis/`: numerical analyses and figure code; the large all-candidate nested grids are regenerated by code.
- `models/`: native LightGBM text models and JSON metadata for pure-solvent and solution permeance.
- `osn_hift/`: inference loader; no pickle execution is needed.
- `reports/verification/`: field-level handbook/supplier and bibliography audits, including access limits.
- `examples/`: design panels from papers absent from the training snapshot, one measured anchor, and expected predictions.

The 2025 input has 5,638 records and 258 canonical papers (262 original strings).
The pure-solvent domain has 1,934 records from 121 papers; solution permeance has
3,190 records from 192 papers. Required transfer descriptors are complete; nine
unsupported optional values are missing. Unspecified xylene is excluded.

## Inference

Use Python 3.10 and `pip install -r requirements.txt`.

```sh
python scripts/predict_released_model.py --task pure_solvent_permeance --input examples/pure_solvent_permeance_panel.csv --anchors examples/pure_solvent_permeance_anchors.json --output predictions.csv
python -m unittest discover -s tests -v
```

Anchor JSON values are measured **log10** permeances, in L m^-2 h^-1 bar^-1 before
the log transformation. Input panels must describe one membrane and contain both
the candidate and anchor solvents. Mixed-solvent feeds and unknown solvent identities
are rejected. A target observation is excluded from its own anchor set. The
unanchored HiFT prior depends on the declared candidate-solvent panel. Use 1–3
compatible measured solvents for the evaluated few-shot setting.

`hift_P` is the point prediction in physical units; `raw_sd_log10_P` is the model's
unscaled Gaussian SD, **not** a calibrated interval or a coverage guarantee. Paper-held-out
calibration analyses and their observed coverage are supplied separately.

## Reproduce the analysis

```sh
python scripts/run_pipeline.py --through 21_si_tables.py
python scripts/export_release_models.py
```

The first command archives existing outputs and reruns numerical stages and figures.
It stops before manuscript compilation, which is outside this data/model release.
The deployment bundles are refitted on the entire corrected **2025-04-08 training
snapshot only**, with seed 0, equal ensemble weights and no prior shrinkage. They
are distinct from held-out benchmark models. Native-file inference was checked
against 153 archived external-evaluation rows over k=0,1,2,3; maximum absolute
prediction error was 2.23e-16. See `reports/model_export_validation.json`.

The comparison export labelled 2026-10-23 was already local when this audit began;
its acquisition log is unavailable. Absence from the 2025 snapshot does not establish
prospective blinding. Performance varies by task, and simple anchored baselines can
match or outperform HiFT. Source-paper shifts and applicability limits remain.
